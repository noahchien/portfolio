# Cryptfall

[繁體中文](cryptfall.md)　／　**English**

A Godot 4 prototype exploring an oblique-view dungeon ARPG with procedural maps, combat, equipment, and Roguelite upgrade choices.

It starts with the question: what if the game worked like this? The prototype gives those ideas a place to be tried, rather than leaving them only in a design document.

## Design and prototype scope

- Warrior, mage, and hunter classes with different weapons and abilities.
- Room and corridor generation, A* enemy pursuit, and floor transitions.
- Real-time combat, equipment drops, three-choice upgrades, and inventory.
- Oblique-view camera, procedural character geometry, and dungeon assets.
- NPC choices, companions, and a foundation for touch controls.

These features are summarized from the existing prototype documentation and project structure. This portfolio update does not represent a fresh, complete verification of every feature.

## My role

Gameplay requirements, product direction, iteration feedback, and acceptance criteria, using AI to help build and revise the prototype. I do not claim all code or artwork was created independently by hand.

## Technology and status

Godot 4, GDScript, procedural maps, grid pathfinding, and 3D scenes. This is a development prototype, not a released game. Mobile device validation and store publishing remain pending. Engine-version notes and the roadmap still need alignment before a public playable build is released.

## Next steps for sharing the project

Capture real gameplay, prepare a downloadable test build, and review asset licensing and packaging before deciding which source code and assets to release publicly.
